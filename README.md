# 📂 QA Pet Projects
**Автор:** Никита Калашников
**Цель репозитория:** Демонстрация навыков ручного тестирования, оформления тестовой документации и базового программирования на Python

## 🎯 Какие навыки демонстрирует репозиторий:
- Анализ требований (Functional + Non-Functional).
- Тест-планирование и тест-дизайн (граничные значения, классы эквивалентности, негативные сценарии).
- Написание чек-листов и тест-кейсов.
- Локализация дефектов и оформление качественных баг-репортов.
- Подготовка итоговых отчётов по тестированию.
- Базовый Python (написание простых консольных программ).
