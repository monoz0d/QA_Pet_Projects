## Примечания

- В чек-листе используется префикс CSC - (Calc System Checklist), в тест-кейсах - NSC- (Number System Calc). Связь между ними отражена в матрице трассируемости.
- Нумерация ID отражает порядок добавления проверок, а не их порядок в документе.
- Все баги фиксируются в `bug_reports.md`  
- Приоритеты:  
  - **Высокий** - критическая функциональность, корректное преобразование чисел  
  - **Средний** - обработка букв, граничные значения, большие числа  
  - **Низкий** - исследовательские проверки
