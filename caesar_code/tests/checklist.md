## Примечания
- Нумерация ID отражает порядок добавления проверок, а не их порядок в документе
- Нумерация ID в чек-листе и тест-кейсах различается, так как чек-лист содержит дополнительные проверки (Smoke, граничные, негативные), которые не вынесены в отдельные тест-кейсы.
- Все баги фиксируются в `bug_reports.md`
- Приоритеты расставлены согласно тест-плану:
  - Высокий - критическая функциональность
  - Средний - важные, но некритичные проверки
  - Низкий - дополнительные и нефункциональные проверки
