Суть тестирования заключается в проверке всех обязательных функций программы

Примечание: BUG-002 был выявлен при анализе кода, а не в ходе ручного тестирования. Тест-кейсы CC-001, CC-006, CC-008 были выполнены на русском алфавите и показали корректные результаты.
